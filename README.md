# TIL
맥 os로 vscode 설치하는 법
git 명령어 학습
iTerm에서 VScode로 연결하는 법
touch 명령어로 폴더 생성
echo로 내가 명령한 단어 다시 받기
echo "Hello World" > README.md 명령어로 README.md 파일에 "Hello World" 입력
echo "Welcome to KANT" >> README.md 명령어로 README.md 파일에 "Welcome to KANT" 추가 입력 ("append")
cat README.md 명령어로 README.md 파일에 입력한 "Hello World", "Welcome to KANT" 받기
history 명령어로 내가 사용했던 명령어 다시 보기
drwxrwxrwx -> d = 디렉토리(폴더) r = 읽기 권한 w = 쓰기 권한 x = 실행 권한
첫 rwx = 소유자 두번째 rwx = 소유 그룹 세번째 rwx = 기타 사용자
